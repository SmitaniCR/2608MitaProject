# よくある質問・回答集(FAQ)

実際の学習者とのやり取りから蓄積された、質問と回答のまとめ。単なるログではなく、
**個人が特定される情報や特定の会社に固有の機密情報を含まない、一般化された形**で
記録する(このスキルは公開リポジトリで管理されることがあるため)。

メンター(Claude)は、モード1(スタート確認)・モード2(実装中の質問対応)・
モード3(完了レビュー)で、該当Stepに関連する項目がここにあれば、
ゼロから考えるのではなくまずこれを参照した上で応答する。

新しい項目の追加方法は`SKILL.md`のモード7(質問・回答の蓄積)を参照。

## 使い方(記録フォーマット)

各項目は以下の形式で、関連するStepの見出しの下に追記する。

```markdown
- **Q**: (一般化された質問)
  **A**: (回答の要点。なぜそうなるかの理由も含める)
```

**見出しはStep番号ではなくidで管理する**(`## <Step名> <!-- id: xxx -->`の形式)。
`CURRICULUM.md`のStep番号は自由に変更してよい方針になったため、番号を見出しに
使うと、番号の振り直しが起きた際に古い見出しが別のStepを指してしまう。idは
変更されない識別子なので、番号が変わってもFAQの参照先がずれない。

**各項目に`(関連Step: <id>)`を書くのは、見出しだけでは関連Stepが特定できない
場合のみ**でよい(通常のStep見出しの下に置く項目は、見出し自体が既にidを
示しているため冗長)。主な用途は「環境・ツール関連」セクションの項目が
特定のidに強く関連する場合(例: `(関連Step: sql-native-query)`)。
